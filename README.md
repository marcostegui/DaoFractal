# DaoFractal

Self-organizing, decentralized network enables real-time data processing and autonomous governance within a secure core system infrastructure.

DaoFractal is built to be simple and practical, focusing on doing one thing well.

## Technology Stack

- rust

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoFractal.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
